# ZERO: Alice — проверка на Android

## 1. Получение APK без компьютера

1. Откройте [GitHub Actions](https://github.com/GrineChannel/ZERO-Alice/actions/workflows/android.yml) в браузере телефона и выберите последний запуск со статусом **Success**.
2. Внизу страницы откройте **Artifacts**.
3. Скачайте `ZERO-Alice-debug` (для диагностики) или `ZERO-Alice-release` (для обычной установки). GitHub скачивает ZIP-архив, а не APK напрямую.
4. Распакуйте ZIP штатным файловым менеджером Android, найдите `app-debug.apk` или `app-release.apk` и откройте его.
5. Если Android блокирует установку, разрешите установку приложений из этого источника только для используемого файлового менеджера или браузера. Не отключайте системную защиту целиком.

**Важно:** используйте APK только из собственного репозитория. Debug и release в текущем CI подписываются одним ключом; при установке новой версии поверх старой подпись и идентификатор пакета должны совпадать.

## 2. Базовая проверка

- Откройте приложение. Убедитесь, что главный экран и настройки не закрываются с ошибкой.
- В настройках проверьте строку версии и номера сборки. Для тестовой ветки ожидается `0.2.0 (сборка 2)` после успешного CI.
- Откройте экран модели и проверьте состояние загрузки.
- При первом скачивании используйте устойчивое соединение и достаточно свободной памяти: файл модели занимает несколько гигабайт.
- Прервите загрузку, затем повторите её: проверяйте корректность возобновления и отсутствие одновременных загрузок.
- После полной загрузки запустите модель и дождитесь статуса готовности. Само наличие файла не подтверждает работоспособность ИИ.
- В чате отправьте «Привет, Элис». Дождитесь ответа и проверьте повторное сообщение.
- Быстро нажмите отправку дважды: не должно возникать двух одинаковых запросов.
- Проверьте копирование переписки, выделение текста и вставку из буфера обмена.
- Перезапустите приложение и проверьте сохранение истории и фактов.
- Попросите Элис запомнить безобидный факт, затем забыть его. После перезапуска убедитесь, что забытый факт не появляется вновь.
- Проверьте голосовой ввод и голосовой ответ, затем переключите скорость речи в настройках.

## 3. Что записать при проблеме

Укажите:
- модель телефона и версию Android;
- версию приложения и номер сборки;
- шаги воспроизведения;
- точный текст ошибки или скриншот;
- происходит ли ошибка с сетью и без неё;
- на каком этапе она появилась: загрузка, запуск ИИ, чат, память, голос или интерфейс.

**Не публикуйте** токены, пароли, личную переписку, ключи подписи или другие секреты в публичных GitHub Issues.

## 4. Критерий готовности

Успешная сборка APK означает только успешную компиляцию и упаковку. Для готовности к версии 1.0 необходимо отдельно подтвердить установку, загрузку модели, генерацию ответов, память, голос и отсутствие критических сбоев на реальном устройстве.
