# ZERO: Alice 0.3.0 — проверка исполнителя задач

## Назначение
Проверить сохранение прогресса, защиту от повторных запусков и безопасную обработку операций с файлами. Проверки ниже — **план**, а не результаты выполненных тестов.

## Ручные сценарии на Android

1. Создать задачу с двумя шагами создания папок в частной рабочей области. Выполнить первый шаг, закрыть приложение, открыть его снова и проверить, что прогресс сохранился; продолжить второй шаг.
2. Выполнить завершённую задачу повторно. Прогресс не должен измениться.
3. Отменить задачу и попытаться выполнить её шаг. Исполнение должно быть отклонено.
4. Создать задачу с шагом «предпросмотр замены элис ...». Запустить команду «выполни шаг элис ID». Содержимое файла не должно измениться, а шаг не должен отмечаться выполненным.
5. Запустить пакетное продолжение задачи с шагом предварительного просмотра. Пакет должен остановиться перед этим шагом.
6. Быстро отправить две команды «выполни шаг элис ID» для одной задачи. Пока первая выполняется, вторая не должна повторять операцию.
7. Проверить неуспешную операцию создания файла с уже существующим именем. Шаг должен остаться незавершённым, ошибка должна появиться в журнале.
8. Проверить асинхронную Minecraft-задачу: повторный запуск во время работы должен отклоняться; после завершения должен учитываться только ожидаемый шаг.

## Ограничения текущей реализации

- Блокировка локальных операций действует в рамках процесса приложения, а не между его перезапусками.
- Операция с внешним эффектом и запись прогресса не являются одной транзакцией. При аварийном завершении между ними повторная попытка требует проверки состояния рабочей области.
- Запуск Minecraft и локальные файловые операции пока используют отдельные механизмы резервирования.
- Не считать приложение полностью автономным, пока не реализованы безопасное восстановление, разрешения на действия и полноценные интеграционные тесты.

## Критерии приёмки

- GitHub Actions собирает APK без ошибок.
- Все сценарии выше пройдены на устройстве.
- В журнале отсутствуют ложные записи о завершённых шагах.
- Стабильная ветка `main` не меняется до подтверждения проверки.
